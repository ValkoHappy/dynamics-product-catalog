# Каталог товаров

Тестовое задание на React, TypeScript, Redux Toolkit, RTK Query, React Router и SCSS Modules.

Демо: https://valkohappy.github.io/dynamics-product-catalog/

## Запуск

```sh
npm ci
npm run dev
```

Основные проверки:

```sh
npm run build
npm run lint
npm test
npm run format:check
```

## Что реализовано

- каталог товаров с карточками, поиском, категориями, сортировкой и фильтрами по датам;
- бесконечная пагинация и синхронизация фильтров с URL;
- отдельная страница товара `/products/:id`;
- избранное на Redux Toolkit с отдельной страницей и сохранением после перезагрузки;
- состояния загрузки, ошибки, пустого результата и отсутствующего товара;
- адаптивная верстка и управление основными элементами с клавиатуры;
- все endpoint’ы продуктов из документации DummyJSON, включая mutation-запросы.

## Структура

- `src/app`: маршруты, Redux store и общая оболочка приложения;
- `src/entities/product`: типы товара, API и карточка товара;
- `src/features`: фильтры, пагинация, избранное и mutation-запросы;
- `src/pages`: страницы каталога, товара, избранного и API-демонстрации;
- `src/shared`: переиспользуемые состояния запросов, изображения и форматирование цены.

Серверные данные хранятся в кеше RTK Query, а в Redux сохраняются только идентификаторы
избранных товаров. Фильтры каталога восстанавливаются из GET-параметров URL, поэтому ссылку
с выбранными параметрами можно открыть напрямую или передать другому человеку.

Запросы создания, изменения и удаления доступны на странице `/api-demo`, но DummyJSON не сохраняет эти изменения
после ответа.
